# ProcureCompare AI

**Intelligent Product Sourcing and Price Comparison Agent**

A validated multi-stage workflow that searches for e-commerce products, extracts their specifications, compares prices, and generates an HTML procurement recommendation report.

The project is implemented in the [`ProcureCompare_AI.ipynb`](ProcureCompare_AI.ipynb) notebook and configured for a local VS Code/Jupyter environment on macOS.

## How It Works

The workflow runs sequentially. CrewAI handles query planning and report writing, while deterministic Python loops control every Tavily and ScrapeGraphAI API call:

1. Generate targeted search queries based on the product, websites, and country.
2. Search the web with Tavily and filter out low-relevance results.
3. Extract product information from e-commerce pages with ScrapeGraphAI.
4. Generate an HTML comparison and recommendation report.

Generated files are saved in the repository-level `ai-agent-output/` directory. The notebook resolves this absolute path from the project location, so it does not change with the kernel working directory:

| File | Contents |
| --- | --- |
| `step_1_suggested_search_queries.json` | Suggested search queries |
| `step_2_search_results.json` | Filtered search results |
| `step_2_search_errors.json` | Search queries that failed and their errors |
| `step_3_extracted_products.json` | Validated products and specifications |
| `step_3_scrape_errors.json` | URLs that could not be extracted and their errors |
| `step_4_procurement_report.html` | Final procurement report |

## Requirements

- Python 3.10 through 3.12 (`crewai==0.114.0` is not compatible with Python 3.13 or 3.14)
- API keys for OpenAI, Tavily, and [ScrapeGraphAI](https://scrapegraphai.com/signup)
- An optional AgentOps API key for observability

## Libraries and Their Purpose

| Library | Purpose in this project |
| --- | --- |
| `crewai[tools,agentops]` | Runs the query-planning and report-writing agents. External data calls remain deterministic Python operations. |
| `agentops` | Records workflow traces and provides a Session Replay link for monitoring and debugging agent activity. |
| `tavily-python` | Searches the web for relevant e-commerce product pages using the queries generated by the first agent. |
| `scrapegraph-py` | Extracts structured product details, prices, images, and specifications from the selected product pages. |
| `pydantic` | Defines and validates queries, search results, prices, and extracted product records. |
| `python-dotenv` | Loads API keys securely from the local `.env` file instead of storing secrets in the notebook. |
| `jupyter` | Provides the interactive notebook environment used to configure, run, and inspect the workflow. |

The OpenAI model is accessed through CrewAI's `LLM` interface and is responsible for query generation and report writing. It never decides which API calls were executed and cannot add products that are absent from the validated extraction data.

`agentops==0.4.21` is pinned for reproducibility. The notebook includes a compatibility adapter for the `_headers` and `_session` attributes removed from OpenTelemetry's HTTP exporter in version 1.45. It also disables AgentOps' separate console-log upload, which can return `401` on the free plan; OTLP traces, LLM spans, and Session Replay remain enabled.

## Why the Tavily API Key Is Required

The deterministic search stage uses `TAVILY_API_KEY` to authenticate with Tavily and executes every targeted query produced by the query-planning agent exactly once. For each query, Tavily returns:

- Relevant page titles and URLs
- Short page-content summaries
- Search relevance scores
- The original search query associated with each result

These results allow the workflow to identify likely e-commerce product pages and discard irrelevant or low-confidence links before scraping begins.

Without this key, the project can generate search queries, but it cannot discover current product pages on the web. ScrapeGraphAI would therefore have no URLs to analyze.

Create a Tavily account and API key on the [official Tavily dashboard](https://app.tavily.com), then store the key locally:

```env
TAVILY_API_KEY=your_tavily_api_key
```

## Why the ScrapeGraphAI API Key Is Required

Tavily and ScrapeGraphAI have two different responsibilities in the workflow:

```text
Tavily → finds relevant product pages
ScrapeGraphAI → extracts structured product data from those pages
```

The deterministic extraction stage uses `SCRAPEGRAPH_API_KEY` to authenticate with ScrapeGraphAI and analyze the validated product URLs returned by Tavily. Each request has a timeout, and extraction failures are recorded separately. For each product page, it extracts:

- Product name and page URL
- Current and original prices
- Discount percentage
- Product image URL
- Important technical specifications
- Search provenance needed to audit and compare products

Without this key, the project can generate search queries and find product pages, but it cannot transform those pages into comparable product records. Consequently, the final procurement report cannot be completed.

Create a ScrapeGraphAI account and API key on the [official signup page](https://scrapegraphai.com/signup), then store the key locally:

```env
SCRAPEGRAPH_API_KEY=your_scrapegraph_api_key
```

## Local Installation

From the repository root, enter this project directory:

```bash
cd agents/procurecompare-ai
```

Using Conda (recommended for Miniconda users):

```bash
conda create --name ai-agent python=3.12
conda activate ai-agent
python -m pip install -r requirements.txt
```

Using `venv`, explicitly select an installed Python 3.12 interpreter:

```bash
python3.12 -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Create your local environment file:

```bash
cp .env.example .env
```

Open `.env` and replace the example values with your API keys. This file is excluded from Git. The notebook reports any missing required key clearly; AgentOps is skipped when its key is absent.

When using VS Code, select the **Python 3.12 (ai-agent)** kernel before running the notebook.
